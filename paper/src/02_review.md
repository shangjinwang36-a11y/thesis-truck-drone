# 第2章 文献综述

本章从四个方面梳理与本文相关的研究：卡车—无人机协同路径问题（2.1节）、动态随机车辆路径与实时恢复（2.2节）、自适应大邻域搜索与数学启发式（2.3节）、学习引导的元启发式与算子选择（2.4节），最后在2.5节归纳研究空白。

## 2.1 卡车—无人机协同路径问题

### 2.1.1 单车单机：FSTSP 与 TSP-D

Murray 与 Chu 最早系统地提出了车机协同配送的两类基本模型[@murray2015]：一是飞行助手旅行商问题（FSTSP），一辆卡车与一架无人机协同服务客户，无人机从仓库或客户点起飞、服务一个客户后在下游客户点或仓库与卡车会合；二是并行无人机调度旅行商问题（PDSTSP），无人机直接从仓库往返服务客户，卡车独立完成其余客户。该文给出了混合整数规划模型与启发式算法，并明确刻画了起飞准备、回收时间与续航约束，后续大量研究沿用了其“节点起降、同步会合”的建模框架。

Agatz 等提出了带无人机的旅行商问题（TSP-D），在“先路由后划分”的思路下给出整数规划模型以及基于动态规划的精确与启发式方法[@agatz2018]。Ha 等将目标从最小化完工时间改为最小化运营成本（包括运输成本和等待造成的浪费时间成本），提出了 min-cost TSP-D 及其 MILP 模型和 GRASP 等启发式[@ha2018]。Carlsson 与 Song 则从连续近似角度分析了一车一机协同相对于单车配送的效率增益，为理解车机协同的潜在收益提供了理论依据[@carlsson2018]。Bogyrbayeva 等尝试用深度强化学习直接构造 TSP-D 解[@bogyrbayeva2023]，反映了学习方法向车机问题的渗透。

上述研究普遍假设：无人机每次只服务一个客户，起降只能发生在客户节点或仓库，并且所有空中投递都能按计划完成。

### 2.1.2 多车多机、多票航次与跨车协作

面向实际配送规模，研究逐步扩展到多车多机。Wang 与 Sheu 建立了多车多机的带无人机车辆路径问题（VRPD）模型，并设计了分支定价精确算法[@wangsheu2019]。Sacramento 等针对多卡车、每车一架无人机的 VRPD 设计了自适应大邻域搜索（ALNS）元启发式[@sacramento2019]，是本文主搜索框架最直接的方法来源之一。Schermer 等提出了求解 VRPD 及其若干变体的数学启发式[@schermer2019]，其中包括允许无人机在道路弧上若干离散点起降的变体。Murray 与 Raj 将 FSTSP 推广到一车多机的 mFSTSP，并刻画了多架无人机在同一卡车上起降时的排队与载荷相关续航[@murrayraj2020]。

多票航次方面，Masmoudi 等研究了配备多包裹舱的无人机车辆路径问题，允许一个航次服务多个客户，并允许无人机在客户节点与卡车会合后进行换电与补货[@masmoudi2022]。Jiang 等提出了多访问、柔性停靠的 VRPD，允许无人机在多个客户间连续服务并由不同卡车回收，采用 ALNS 求解并以线性规划评价给定结构的时序[@jiang2024]。

跨车协作是近年的研究热点。Kim 等研究了面向优质配送服务的多车多机协同，允许无人机由一辆卡车在客户点放飞、由另一辆卡车在另一客户点回收[@kim2025]。Long 等面向城市应急响应提出了动态的卡车—无人机协作与集成路径规划，允许跨车回收，采用禁忌搜索并以递归方式评价时序[@long2024]；Zhao 等在此基础上给出了一种分解式数学启发式，将需求分配、卡车路线与无人机调度分层协调[@zhao2025]。Fan 等研究了带灵活跨车操作与机位约束的车机协同路径问题，提出了带自适应大邻域扰动的模因算法[@fan2026]。需要指出，这些文献中的“动态”多指车机之间可变的协作关系，而非执行过程中逐步揭示的随机信息；它们通常也限制起降只能发生在客户节点或仓库。

### 2.1.3 途中起降与连续放飞位置

当卡车不必停车即可放飞或回收无人机时，起降位置不再局限于离散节点。Marinelli 等较早提出“途中（en route）”车机配送，允许卡车在道路弧上的某一点放飞或回收无人机[@marinelli2018]。Masone 等研究了带边上起降的多访问无人机路径问题（MVDRP-EL），用全局连续方法在道路边上确定起降位置，并结合离散与连续改进的迭代方法求解[@masone2022]。Thomas 等研究了考虑无人机调度与途中作业的一车多机协同配送系统[@thomas2024]。规范核对的文献也显示，Jiang 等与 Long 等均将道路弧上离散起降或行驶中起降列为未来研究方向[@jiang2024; @long2024]。

本文采用“放飞可沿卡车实际轨迹连续选择、回收必须在客户点停车完成”的非对称设定：放飞位置由道路弧参数 $\lambda\in[0,1]$ 连续表示，而回收必须满足车辆真实到场、司机与通道可用和机位可预留等同步条件。这一设定介于纯节点模型与全连续起降模型之间，是本文的设备与作业假设，而非对现有商用平台能力的证明。

### 2.1.4 能耗与充电建模

无人机能耗模型直接影响航次可行性。Dorling 等提出了随载荷与电池质量线性变化的多旋翼功率近似，并据此研究了无人机配送路径问题[@dorling2017]；Zhang 等系统比较并评估了多种配送无人机能耗模型，指出不同模型对同一任务的能耗估计可能相差显著[@zhang2021]。在车机协同中，大多数研究以固定续航时间或固定航程表示无人机能力，部分研究考虑了换电或在车充电，但很少同时考虑“逐段真实载荷能耗、空中等待能耗、行驶期间车载充电及车辆供电预算”。本文沿用规范给定的载荷相关巡航与悬停能耗、按阶段建立能量链，并把车载充电作为受单槽功率、整车功率与车载交流电量预算约束的可选决策。

### 2.1.5 不确定性与动态车机协同

已有考虑不确定性的车机研究主要分为两类。第一类为静态的鲁棒或随机优化：Sun 等研究了旅行时间不确定下的车机协同鲁棒优化[@sun2026]；Wu 等研究了人道主义物流中带柔性停靠无人机的鲁棒车辆路径问题[@wu2027]；Dukkanci 研究了不确定条件下兼顾选址与路径决策的车机配送问题[@dukkanci2026]。这类模型在执行前给出对不确定性免疫的方案，但不涉及执行中的重新规划。第二类为动态问题：Ulmer 与 Thomas 研究了异质车队（无人机与车辆）下随机到达请求的当日配送[@ulmer2018]；Chen 等用深度 Q 学习为车辆与无人机的当日配送分配决策[@chen2022]；Gu 等研究了同时包含计划配送与随机到达取件请求的动态车机路径问题[@gu2023]。这类研究的随机性主要来自需求的到达，而非已计划空中投递在执行时的失效。

综上，现有车机文献尚未建立“到客户后才揭示空中交付不可用，而地面送达与车载回收仍可行”的失效机制，也未研究失效后无人机携带失败包裹与卡车会合、交接并改为地送的完整恢复过程。

## 2.2 动态随机车辆路径与实时恢复

### 2.2.1 动态与随机车辆路径问题

动态车辆路径问题（DVRP）是指部分输入在执行过程中才被揭示、需要据此调整路线的问题。Pillac 等按信息的动态性与随机性对 DVRP 进行了分类综述[@pillac2013]；Psaraftis 等回顾了 DVRP 三十年的发展[@psaraftis2016]；Ritzinger 等综述了动态与随机车辆路径问题的模型与方法[@ritzinger2016]；Soeffker 等从规范性分析（prescriptive analytics）视角梳理了随机动态车辆路径的研究，强调对未来信息的利用方式[@soeffker2022]。Powell 提出了随机优化的统一框架，将序贯决策问题的求解策略归纳为策略函数近似、成本函数近似、价值函数近似与前瞻策略等几类[@powell2019]。

在求解策略上，一类方法在每个决策时刻求解确定性的剩余问题（即“事件触发的重优化”或“滚动重优化”），另一类方法通过情景采样、近似动态规划等方式考虑未来随机性。Bent 与 Van Hentenryck 提出了基于多情景的规划方法，在每个决策点用采样情景评价候选决策[@bent2004]。按 Powell 的分类，本文的方法属于“只利用已观察信息、求解确定性剩余问题”的一类策略：规划器在每次失效揭示后，基于公开快照重新优化剩余计划，不对未揭示的失败客户进行情景采样。这样做的理由是，本文的失效客户集合在全部客户中随机抽取、数量仅 1—2 个，且规范要求严格的信息隔离；引入前瞻策略属于另外的研究设计。

### 2.2.2 车辆路径中的干扰管理与实时恢复

干扰管理（disruption management）研究计划执行中发生意外事件后如何以最小代价恢复运营。Li 等提出了车辆重调度问题（VRSP），研究车辆在途中故障后如何重新指派其余任务[@li2007]，并进一步研究了带时间窗的实时车辆改路问题[@li2009]。Mu 等研究了车辆故障下的车辆路径干扰管理，并以禁忌搜索求解[@mu2011]。Eglese 与 Zambirinis 综述了公路货运中车辆路径与调度的干扰管理研究[@eglese2018]。

这些研究的共同特点是：干扰发生后需在“偏离原计划的代价”与“新计划的质量”之间权衡，并须尊重已执行部分。本文的恢复问题与之类似，但具有三点特殊性：（1）干扰对象是无人机的单次空中投递，而非整车故障；（2）失败包裹物理上仍在空中无人机上，恢复必须先完成车机同步回收，涉及无人机剩余电量、空中等待能耗与车载机位；（3）回收车辆既可能是原放飞车，也可能是其他卡车，这正是 S/X 政策比较的对象。

## 2.3 自适应大邻域搜索与数学启发式

### 2.3.1 LNS 与 ALNS

大邻域搜索（LNS）由 Shaw 提出，通过反复“移除—重插”解的一部分来探索大规模邻域[@shaw1998]。Ropke 与 Pisinger 在 LNS 基础上提出了自适应大邻域搜索（ALNS）：维护多个移除与修复算子，根据各算子的历史表现以分段更新的权重进行轮盘选择，并以模拟退火（SA）[@kirkpatrick1983]作为接受准则[@ropke2006]。Pisinger 与 Ropke 进一步把 ALNS 作为统一框架应用到多类车辆路径问题[@pisinger2007]。ALNS 现已成为车机协同问题最常用的求解框架之一[@sacramento2019; @jiang2024; @fan2026]。

关于 ALNS 的组成要素，Windras Mara 等对 ALNS 的算法设计与应用进行了全面综述[@mara2022]；Voigt 回顾并比较了车辆路径 ALNS 中常用的移除与修复算子[@voigt2025]；Santini 等比较了 ALNS 中多种接受准则，表明接受准则的选择会显著影响算法表现[@santini2018]。值得注意的是，Turkeš 等对大量 ALNS 文献进行元分析，发现自适应选择层对解质量的平均贡献相对有限，且依赖于具体问题与算子设计[@turkes2021]。这一结论提示：在本文问题上，是否需要以及如何改进算子选择机制，应通过受控实验而非默认假设来判断。

### 2.3.2 数学启发式

数学启发式（matheuristic）是元启发式与数学规划的结合。Archetti 与 Speranza 综述了路径问题中的数学启发式，将其归纳为分解方法、以数学规划为改进步骤的方法和基于列生成/分支定价的启发式等类型[@archetti2014]。在车机问题中，Schermer 等的 VRPD 数学启发式[@schermer2019]、Zhao 等的分解式数学启发式[@zhao2025]以及 Jiang 等在 ALNS 中以 LP 评价时序的做法[@jiang2024]都属于这一范畴。Hendel 将 ALNS 思想用于一般混合整数规划，在多个受限子 MIP 邻域间自适应地分配求解工作[@hendel2022]。在求解器方面，开源的 HiGHS 线性/混合整数规划求解器[@huangfu2018]已通过 SciPy[@virtanen2020] 提供 Python 接口，使得在启发式中嵌入精确子问题的工程门槛显著降低。

本文的数学启发式包括三个层次：ALNS 负责离散结构搜索；固定结构下的时序与充电由 LP 求解；失败后的恢复决策由 MILP 子问题精确求解（方法 B）。

## 2.4 学习引导的元启发式与算子选择

机器学习与组合优化的结合是近年的研究热点。Bengio 等从方法论层面总结了机器学习在组合优化中的三种角色：端到端学习、学习配置算法参数、以及在算法内部学习决策[@bengio2021]。Karimi-Mamaghan 等专门综述了机器学习服务于元启发式的方式，包括算法选择、参数调整、算子选择和解的初始化等[@karimi2022]。

算子选择问题在超启发式（hyper-heuristic）领域有较长的研究历史。Burke 等综述了超启发式的研究现状，其中基于强化学习的低层启发式选择是重要分支[@burke2013]。Q-learning[@watkins1992]因其表格形式简单、无需环境模型，常被用于算子选择：Qin 等提出了基于强化学习的超启发式求解异质车队车辆路径问题[@qin2021]；Wang 等提出了强化学习引导的 ALNS 求解带时间窗车辆路径问题[@wang2025]。在深度强化学习方面，Kallestad 等提出了通用的深度强化学习超启发式框架[@kallestad2023]；Reijnen 等提出 DR-ALNS，根据搜索状态在线选择算子、调整参数并控制接受准则[@reijnen2024]；Johnn 等提出了图强化学习驱动的神经 ALNS 框架[@johnn2024]。多臂老虎机是另一类在线学习方法：Cai 等提出的 Balans 以多臂老虎机在线选择 ALNS 邻域求解混合整数规划，无需离线训练[@cai2025]。

上述研究多以静态问题为对象，学习信号来自单次求解过程。在本文的动态恢复情境中，每次失效触发的重规划预算有限（规范默认每次恢复 60 s 墙钟或 1000 次完整评价），可用于在线学习的样本较少；同时，规划器不得读取隐藏环境信息，学习所用的状态特征必须完全来自公开的搜索过程。因此，本文采用低维离散状态与表格 Q-learning（方法 A），以控制学习开销并保证信息隔离。

归纳起来，现有研究存在以下空白：

1. **失效机制空白。** 现有车机模型多为确定性或针对旅行时间、需求到达的不确定性，尚未刻画“到点才揭示的空中交付失效”，以及失败包裹仍在机上、必须经“回收—交接—地送”才能妥投的物理过程。
2. **恢复过程与政策比较空白。** 跨车回收在静态模型中已被证明可以提升协同灵活性，但在执行期失效恢复中，限制原车回收与允许跨车回收的差异尚缺乏在相同环境、相同预算下的配对比较。
3. **连续放飞与能量—充电耦合空白。** 同时考虑轨迹连续放飞、逐段载荷能耗、空中等待能耗、行驶充电与车载供电预算的多车多机模型较少，在动态恢复情境下更为少见。
4. **求解方法空白。** 现有车机 ALNS 多采用分段轮盘权重选择算子，恢复决策也多由启发式插入完成；将恢复决策写成精确 MILP 子问题并与 ALNS 融合、以及在有限重规划预算下以强化学习选择算子，在动态车机恢复问题上尚未见系统研究。

本文针对上述空白开展研究，第3章建立模型，第4章给出算法。
