## Hard constraints

- [x] **No 0.2 failure weight, for S or for X.** Planning uses `3/(2N)` and `1/(N(N−1))`. `weight_reaction = 0.2` is the ALNS operator-weight reaction.
- [x] **X is one integrated search.** The screen sits inside the same nominal loop. There is no second phase and no hand-off from S.
- [x] **No experiment setting was changed.** Rules, failure model, probabilities, budgets (1000 / 1000 / 60 s), seeds, fleet, energy, H, prices, statistics, and the 0.08333 kWh margin are unchanged.
- [x] **The screen is shared.** S and X call the same function, with the same rule: charge a candidate only when the timeline price beats the champion.

## Choice

**(B).** The round-10 screen prices the real schedule (distance, driver time including waits, depot refill, and, on the nominal, the v1.3 failure terms) and compares that number with the best plain J. That is a full plain-J evaluation. It is a base mechanism, not an X-only cross operator, so both strategies must have it.

(A) would charge that work only on X. X would again spend its 1000 on crosses while S spends the same 1000 on same-truck moves, which is the gap round 10 was trying to close, and it would still be unequal work.

Under (B) the charged evaluation means the same thing for both: the candidate passed the screen. Screens are extra work. They are counted below. A screen that does not beat the champion is not charged and is not accepted.

Recovery uses the same rule on catalog candidates, priced as execution cost rather than plain J, because the failures have already been revealed. Cross rescues also sit on a `SKIP` / `CROSS` roulette. A charged cross that does not beat the current best cost cuts `CROSS` to a quarter and adds 2 to `SKIP`, so later draws stay on same-truck recovery.
