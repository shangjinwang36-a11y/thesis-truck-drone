## Every change that touched S

1. **Best-J archive.** Every feasible nominal evaluation is scored with plain v1.3 J. The best one is stored. At publication, if a later stage (final descent, coordinate polish, or the cross-margin repair) would emit a worse J, the stored plan is restored. S and X use the same function. Round 8’s R50 result was not a dropped champion: `n_cross_before_repair` was 0, so the four crosses that improved J had already been beaten, inside the search, by a later plan with a better plain J. The archive makes that comparison explicit so a later stage cannot undo it.
2. **Infeasible schedules are not charged.** Before a v1.3 nominal geometry evaluation, S and X run the real scheduler. A failure does not spend one of the 1000 evaluations. R50’s S search skipped 342 such trials.
3. **Four-evaluation descent on a new same-truck champion.** Deterministic, same-truck only, S and X. It runs when that champion is accepted and at least four evaluations remain.

## Why the R50 crosses were not published

A cross is recorded as `CROSS_INSERT / best` when its plain J beats the champion at that iteration. On round 8’s R50 that happened four times, and the plan handed to the margin repair contained **zero** crosses. A later same-truck plan had a better plain J, and the publisher kept that plan. That is the correct champion, not a dropped one. The archive added this round stores every feasible J and restores it if descent or repair would replace it with a worse one. On this run the published X plans are that archive: where the best J is a cross (C100), the published plan has two crosses; where no cross was ever the best J (R50), the published plan has none.
