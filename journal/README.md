# Journal packaging for Computers & Operations Research

Files in this folder were collected on 12 November 2026 (Asia/Shanghai) for a thesis / SCI submission on truck-drone cooperative delivery.

- `journals_comparison_zh.md` — journal shortlist, CAS zones, IF, fit.
- `journal_rules_zh.md` — Chinese summary of formatting and AI-declaration rules.
- `guide_for_authors.md` — cleaned official Guide for Authors (Wayback 2024-04-15 of the live ScienceDirect page).
- `elsarticle.zip` / `elsarticle/` — official Elsevier `elsarticle` LaTeX class from CTAN (https://ctan.org/pkg/elsarticle). Use `elsarticle-template-harv.tex` and `elsarticle-harv.bst` (author-year), not the numbered templates.
- `els-cas-templates.zip` / `els-cas-templates/` — official Elsevier CAS single/double-column LaTeX templates from CTAN. Optional; COR initial submissions do not require camera-ready two-column layout.
- `sources/` — raw Wayback HTML, extracted text, and the official open-access options page.

There is no official journal-specific Microsoft Word template. Elsevier’s author support page states that Word manuscripts should follow the Guide for Authors with a simple layout. CRediT roles are entered in Editorial Manager.
