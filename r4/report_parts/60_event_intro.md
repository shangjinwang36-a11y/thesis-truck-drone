**方法（明确为条件统计）**：对 X 回合里的每个失败事件，在**同一状态**（同一残余计划、同一快照、同一已失败集合）上再跑一次 S 的恢复（同参数、同 1000 评价预算、同随机流种子），事件节省 = 成本(S 恢复后的全班计划) − 成本(X 恢复后)。这样比较的是"同一时刻 S 与 X 各自能做出的最好恢复"，不受后续失败路径分叉影响。
- "X 选跨车的事件"=最终计划中失败航次由≠原放飞车的车接回；同车事件的节省理应≈0（仅搜索噪声）。
- 以下数字是**以发生了跨车恢复为条件**的，不是总体平均；总体平均见第 3、6 节。必须在论文里这样表述（"当跨车接机被采用时，每次平均节省…"），不能当作总体效果。
- 特征用 Spearman 秩相关 + 前 1/3/其余对比；样本量小时只作讨论线索。
