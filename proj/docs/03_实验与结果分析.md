## 0. 结论速览

| 指标 | 结果 |
|---|---|
| 完成并核验回合 | 114 / 120（3 个环境两侧均 `STOPPED_NO_FEASIBLE_SUFFIX`） |
| 实际观察到空中失效的回合 | 34 / 60 环境（33 个 1 次、1 个 2 次、26 个 0 次） |
| 配对成本差 Δ=C_S−C_X | n=57，均值 **+1.45 元**，标准差 5.00，最小 −2.08，最大 +31.57 |
| 差值方向 | X 更便宜 13 次，相等 43 次，X 更贵 1 次 |
| 均值 95% 近似区间（t 分布） | +1.45 ± 1.50 元 → **区间跨 0，不能宣称显著** |
| 异常回收动作 | 62 次：同点/原车 23、异点/原车 26、异点/跨车 13、同点/跨车 0 |
| 相对名义计划成本变化 | S 平均 +0.22%，X 平均 −0.07% |

**解读**：跨车回收（X）在 13 个环境中被实际选择，且这些环境的成本都低于 S；但 43 个环境两侧完全相同（跨车无可行/无收益），另有 1 个环境 X 反而更贵。逐 seed 差值的正负与零全部保留，符合规范 5.2 的预期。**在 10 个环境种子的样本量下，X 的平均收益不显著**。

## 3. 恢复动作的两层统计

按 recovery_id 的实体动作（62 次携带已观察失败票的异常回收）：

| 分类 | 次数 |
|---|---|
| 同点（回收客户=失败客户）× 原车 | 23 |
| 同点 × 跨车 | 0 |
| 异点（回收客户≠失败客户）× 原车 | 26 |
| 异点 × 跨车 | 13 |

- 同点回收占 23/62 = 37%，与“失效客户原地等车”理论一致；同时 39/62 为异点回收，说明**继续飞行到其他客户/车辆接机**同样是常用恢复方式。
- 跨车回收全部发生在“异点”：X 的收益来自**把机体交给另一辆更早到场或更顺路的车**，而不是把车叫到失效点。
- R100 的 8 个配对全部为 0：该图失效票所在航次的放飞车通常就在附近，且其余车辆无空余机位（每车 2 机位、机上已有 1 架）。

## 4. 可行性、失败与调试记录

3 个回合（R50 seed10、R100 seed3、R100 seed9）在两侧均返回 `STOPPED_NO_FEASIBLE_SUFFIX`：失败发生时，
受影响机体或同车其他在飞残段的余电无法覆盖“飞到任一客户点 + 回收悬停 + 等待”的能量需求，
现有候选全部被充电 LP 判为不可行。按规范 12.7，保留真实前缀、不直飞仓库、不补抽故障，状态如实记录。

**调试过程中修复的关键缺陷**（均已复现、定位并修复）：

1. **无人机链时间未强制**：同一架机的两个航次可重叠执行，导致名义计划“虚假可行”。修复：按“上一航次回收结束 + U”限制下一次 P 的开始，并在固定点迭代中传递可行时刻。
2. **卡车未等待无人机真实到场**：固定点里用了回收开始时刻而非无人机到达时刻。修复：记录 `drone_arrival` 并逐轮迭代。
3. **截断点状态丢失**：多次重规划时 `delivered`、前缀里程、车载交流电被重置，导致成本重复/漏计。修复：截断时累加上一快照。
4. **机位检查重复计数**：把“在车区间”和“放飞区间”重复计算，错误地把可跨车回收判为 3 机占位。修复：以“[在车起始, 放飞结束]”为一个占用区间，回收另计预留。
5. **空中残段起点错误**：服务/等待阶段的 `x1` 未存坐标，残段从 (0,0) 起飞。修复：按已执行阶段回放坐标。
6. **恢复池含已交付票**：重建后缀时把已交付包裹重新插入，造成重复交付与能量不可行。修复：池 = 未交付 − 在飞固定。
7. **失败票悬停能量重复扣减**：修复为“失败时刻余电 − 悬停(t_cut−t_f)”。

## 6. 局限与后续工作

1. **S/X 差异不显著**：10 个环境种子的配对均值区间跨 0；需要增加环境重复或构造“原车远离失效点”的场景来放大政策差异。规范 5.3 已明确不得据此宣称优越性。
2. **跨车只在初始恢复枚举中决策**：外层 ALNS 的移除/修复不改变已开始的残段回收车，因此 X 的搜索空间没有被充分展开（当前 13/60 环境选择跨车）。
3. **时序为前向最早可行**：规范要求的三阶段 LP（参考构序 + 成本 + z）被“前向传播 + 分阶段充电 LP”替代；不保证时间维全局最优，但成本与能量按真实口径核算。
4. **局部事件重排为枚举而非 MILP**：窗口仍限制在 ≤6 个同刻/相邻事件，但尚未实现 HiGHS 整数模型。
5. **正式实验未按 60 s 预算执行**：所有输出均记录实际预算与 `algorithm_variant`，正式论文使用前须按默认预算重跑并复核。
