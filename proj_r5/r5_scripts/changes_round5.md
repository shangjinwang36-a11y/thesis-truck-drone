## 5. X 搜索停滞的根因（C100 种子5 第1次重规划）与修复
**现象**：同一状态同一初始解(460.47)，S 搜到 438.2，X 只到 460.3；X 的 local_reorder 21 次 / MIP_RETURN 40 评价 / 0 次 new_best。
**排除**：
- MIP_RETURN 多不是原因而是结果：`local_reorder` 在“停滞 ≥ mip_stagnation_rounds”时触发，X 没有新最优 → 停滞计数累积 → 触发更多。两边算子权重/选择/接受规则同一份代码（无 strategy 分支，仅恢复目录的候选范围不同）。
**定位**（r5/dbg2.py 逐评价对拍，S/X 同种子同状态）：前 100 个评价序列逐位相同；第 100 个评价起分叉：`RECOVERY_INITIAL_BASE`（即 `try_recovery_reassign`，每 10 轮一次）在 S 返回不可行，在 X 返回可行的 468.02。
**根因（真 bug）**：`try_recovery_reassign` 的候选是在“名义残余计划 base/res_plan”上按目录条目重建的，**不含当前 ALNS 进展**；但采用条件是“优于当前解 cur_ev”（`_better(e_r, cur_ev)`），一旦成立 `cur_plan` 被整体替换为这个“接近初始”的计划，已累积的 ALNS 改进全部丢弃（单元证据：C50 forced3，旧规则采用了比全局最优还差 +0.65 的候选，gap_max=+0.6485）。X 的目录更大（可行的跨车条目更多），被“重置”的次数是 S 的约 3.6 倍（p=0.1 全体：reassign 采用 X 79 次 vs S 22 次），所以是对 X 不利的无意偏差（并非偏向 X）。
**修复（对称，S/X 同一规则，预算不变）**：新增 `AlgorithmConfig.reassign_adopt_only_if_best`（默认 False=旧行为，保证旧结果可复现）；True 时目录候选只有在**优于全局最优**时才替换当前解。第五轮之后的新跑用 True。

## 7. 短视/路径依赖（X 当下更便宜、后面更贵）——对称的改进方案（仅提出，未实现）
**现象证据**：C100 s2(p=0.1)：第3次重规划 X 跨车接机 445.4 < S 449.9，但随后下一次失败代价 X +98 对 S +28（X 卡车 t1/t2/t4/t7 多开 23 km、多约 3000 s 工时，最终 570.1 vs 489.5）。事件触发的恢复每次只最小化“当前余程成本”，没有计入当前决策对后续失败的脆弱性（接机车被占用/位置偏远/机位与电量余量被消耗）；跨车选择因为可选项更多，更容易选到“眼前省钱、后面僵硬”的方案。逐事件配对口径（同状态同事件）不受影响，但端到端受影响。
**原则**：对 S 与 X 用同一个目标函数、同一预算、不设配额/惩罚，只改“恢复目标”。
1. **鲁棒恢复目标（推荐）**：恢复评价 J = C_res + λ·R，其中 R = 对“下一次失败”的期望追加成本的代理，用确定性代理计算：对每个仍在空中的、尚未放飞的航次 j，估计其失败概率 p（已知的 p 或由已观察频率估计）× 该航次失败后最便宜的回收成本（S 为原放飞车最近的后续停靠点绕行；X 为任意车），即 R=Σ_j p·c_rec(j)。S/X 用同一公式，只有各自可行的回收集合不同（X 的 c_rec 更小，所以 X 会因“后续更灵活”被正确地奖励，而不会因眼前省钱而被误导）。需要 p 的信息来源：模型假设（设计参数，不泄露隐藏环境）。
2. **松弛储备（slack reservation）**：在恢复计划中为每辆车保留最小的时间/电池/机位余量（如 H 余量的一部分、每车至少 1 个空机位、换电电池余量），对 S/X 同一阈值；防止 SWAP_CANNOT_FIX / SLOT_OVER / H_EXCEEDED 这类 p≥0.2 时的 STOPPED。
3. **滚动视野(lookahead) 评价**：对候选方案做 k 次（如 4 次）采样的“下一次失败”仿真（共同随机数，S/X 同一组样本），取平均成本作恢复目标（样本平均近似，成本 = 评价预算×k，需把 k 个仿真计入同一预算以保持公平）。
4. **兜底**：当链/电量/机位不可修复时，允许把后续空送包裹转地面（“全地面兜底”），使 STOPPED 只在 H 真不可行时出现，同时报告兜底使用率。
**建议顺序**：先 4（兜底，纯可行性，不改变成本口径）+ 2，再评估 1；3 开销最大。都要有 S/X 对称的消融与全表。
